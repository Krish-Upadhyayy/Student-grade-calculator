# Student Grade Calculator

A simple Java console application that calculates a student's percentage and grade based on marks entered by the user.

## Features
- Input student details
- Calculate percentage
- Assign grades
- Validate marks input
- Display formatted result

## Technologies Used
- Java
- OOP Concepts
- Functions
- Loops
- Conditional Statements

## How to Run

1. Compile the program
   javac StudentGradeCalculator.java

2. Run the program
   java StudentGradeCalculator# Student-grade-calculator
